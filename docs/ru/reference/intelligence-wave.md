# Волна интеллектуального анализа: возможности и границы

Это проверенный локальный вертикальный срез, а не полная v1-реализация анализа
или поиск промышленного масштаба. См. [AI-провайдеры эмбеддингов](../getting-started/ai-providers.md)
и проверяемый [пример AI-профилей](../../../deploy/ai-profiles.example.json).

## Что уже работает

Неизменяемый вид проекта может хранить исходники, AST-фрагменты, символы и
факты связей. Для Go `go/types` находит локальные межфайловые символы, ссылки,
вызовы, чтения и записи. Внешние пакеты и все сочетания build tags он не
обещает разрешить полностью.

WASM-помощник синтаксиса разбирает C, C++, C#, Java, JavaScript, TypeScript,
TSX и JSX. В SurrealDB сохраняются имена, члены, параметры, значения enum и
атрибуты. Запрашивайте эти не-Go факты через `syntax_query` или HTTP
`POST /syntax/query`; устаревший `/types` пока работает только для Go. Это
факты навигации, а не компиляторно разрешённые межфайловые вызовы, CFG или
поток данных.

Поиск объединяет лексический BM25, поиск символов, структурные совпадения по
нормализованным хешам, семантическое ранжирование точным cosine, reciprocal-rank
fusion и необязательный reranker. Структурный поиск не является общим MinHash,
а точный cosine не означает HNSW или векторный индекс. Контекст родителя и
потомка ограничен.

Есть версионированные контракты `code`, `symbol`, `context`, `documentation`,
`architecture`, `change`, `error` и `api`. Текущие producer создают code,
symbol, context, documentation, error и API. Для architecture и change producer
нет.

HTTP содержит POST-методы retrieval/search, graph/query, context,
embeddings/index, AI/probe и syntax/query. MCP предоставляет 18 инструментов в
области workspace/project/view, включая retrieval, context, graph, reads/writes,
embedding index, AI probe и syntax queries, а также исходные project/search/type/status.

## AI-профили

JSON-профили настраивают Ollama, LM Studio/OpenAI-compatible, удалённые и
Docker-host провайдеры. В примере есть квантизованные aliases Qwen3 embedding
4B/8B; размерность проверяется, чтобы не смешивать записи. Конфигурация не
подтверждает доступность модели: её нужно загрузить или импортировать, затем
выполнить probe. Проверки doctor и Docker API прошли с LM Studio и моделью
`text-embedding-qwen3-embedding-8b` (Q8_0), размерность 4096. Восемь представлений
учебного проекта сохранены в SurrealDB и использованы в semantic/hybrid search.
Ollama на стандартном локальном порту отсутствовал. Unit-тесты используют
синтетические векторы; выполненные проверки не измеряют качество поиска.

## Матрица приёмки

| Область | Проверенный результат | Граница |
|---|---|---|
| Go | AST, члены, локальные межфайловые ссылки/вызовы/чтения/записи | Частичный `go/types`; нет полной поддержки внешних пакетов и build tags. |
| C/C++/C#/Java/JS/TS/TSX/JSX | AST, объявления и члены сохраняются | Нет компиляторной семантики, CFG/DFG и межфайлового разрешения. |
| Текст и символы | Лексический BM25 и поиск символов в области видимости | Нет заявления о FTS промышленного масштаба. |
| Структурный поиск | Кандидаты по нормализованному хешу | Не общий MinHash и не доказательство семантической эквивалентности. |
| Семантический поиск | Точный cosine, hybrid RRF, необязательный reranking; реальные embeddings LM Studio | Нет HNSW и измеренного качества поиска. |
| Linux Docker test target | Прошли `go test -race` и fixtures syntax helper для каждого указанного языка | Это результат test target, а не runtime smoke. |
| Windows и Compose | Прошли Go-тесты, `go vet`, интеграция SurrealDB и runtime smoke нескольких языков | Маленькие fixtures, без заявления о масштабе. |
| Хранение | Проверены graph/retrieval, синтетические 3-D векторы и реальные векторы LM Studio размерности 4096 | Точный digest файла модели фиксируется оператором отдельно. |

Это точные зафиксированные результаты проверки. Коммиты `9277db0` и `641db16`
предшествуют волне интеллектуального анализа и не являются её свидетельством.

## Что остаётся

Для полной v1 ещё нужны семантика уровня SCIP для пяти языков, CFG и
межпроцедурный анализ, связи SQL/API/events, интеллект тестов и истории.
Возможности на основе GNN — исследование после v1. Контракт или пункт roadmap
не доказывает, что эта функция уже работает.
