# Очередь исследования ChunkHound

Локальный референс: `C:\Work\valio\chunkhound`, ревизия
`2ab775354d8d378bdacc8ea76b51a588362cfb99`. Перед переносом сверяем LICENSE,
лицензии зависимостей, реализацию и тесты. README заявляет контекст по текущему
коду, Git-истории и техническим веб-источникам, поиск без API-ключей и работу
с внешними и локальными embedding-провайдерами. Это перечень для исследования,
а не подтверждённые возможности valio.code.

Порядок проверки и переноса:

1. Синтаксический чанкинг, метаданные и сохранение координат исходника.
2. Гибридный поиск, повторное ранжирование и цитируемая сборка контекста.
3. Конфигурация Ollama/OpenAI/VoyageAI: профили, размерности, ошибки и batching.
4. Исследование изменений Git с явной привязкой ответа к двум версиям.
5. Наблюдение файлов, инкрементальное обновление и восстановление индекса.
6. MCP-сценарии исследования и бюджетирования контекста.
7. Связь технической документации и внешних источников с кодом; только
   по явной политике доступа и с раздельным происхождением evidence.

У каждой задачи будут исходные файлы/тесты референса, описание пользы,
зависимости от нашего плана, схема адаптации к Go/SurrealDB, инвалидация,
проверки ошибок, независимые fixtures и измерения качества. Автоматическое
копирование проекта, подключение его БД и перенос маркетинговых обещаний
не входят в постановку задачи.
