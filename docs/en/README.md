# valio.code documentation

`valio.code` is a Software Intelligence Graph that keeps Workspace, Project,
Repository and Worktree distinct. It is an early vertical slice, not a complete
v1 implementation. See the [implementation backlog](reference/implementation-waves.md)
and [validation record](reference/validation.md) before relying on a capability.
